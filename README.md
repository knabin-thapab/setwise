# Setwise

Free 1099 quarterly estimated tax calculator and financial toolkit for freelancers and independent contractors.

## Features

- **1099 Quarterly Tax Calculator**: Estimates federal self-employment tax, federal income tax, and all 50 state income taxes for 2026.
- **50-State Tax Directory**: Detailed flat and progressive bracket rules for all 50 US states.
- **Freelance Invoice Generator**: Client-ready invoice builder with automated quarterly tax set-aside calculations and PDF export.
- **Profit Margin & True Hourly Rate Calculator**: Shows real take-home earnings and true hourly wage after expenses and taxes.
- **Privacy-First**: All computations run client-side in the browser. Zero financial data stored or transmitted.
- **Fully Mobile Responsive**: Optimized for smartphones, tablets, and desktops.

## Tech Stack

- React 19
- TypeScript
- Vite 8
- Tailwind CSS v4
- React Router DOM

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build
```
